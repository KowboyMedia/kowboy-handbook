# Kowboy handbook: phase "Discover"

Version 2026-11-16o.

## Discover

When: a project starts, a feature is larger than one item, or the operator describes a wish.

- Read everything given. Ask nothing yet.
- List the features: each in one sentence of value to the user, marked now or later, and what is out.
- List the decisions the features need: each a question in plain words with at most three options, whether it can be undone, and a recommendation.
- Name the risks and unknowns and the cheapest way to find out. Unknowns go first.
- Bring the decisions in rounds of at most five, the most binding first; the rest wait in `docs/open-questions.md` for the next round. Record each answer as it comes.
- Write the plan from the answers. The first item is the riskiest unknown or the thinnest slice that proves the design.

End of the phase.
