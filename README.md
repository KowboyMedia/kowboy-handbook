# Kowboy handbook

`HANDBOOK.md` is how Claude works at Kowboy: a few company rules, how to build software, how to
communicate. It replaces everything that was here before, which is kept in the git history under
the tag `archive-2026-11-16`.

## Using it

Paste `HANDBOOK.md` into your Claude preferences (claude.ai, Settings), so it applies to every
chat and coding session. A repository may add its own `CLAUDE.md` for what is true only there.

## Changing it

Keep it short. A new line earns its place only by fixing a problem that actually happened.
